# --- Revolt chat platform: deliberately NOT installed (accepted gap, not an oversight) ---
# revolt.py==0.1.6 (the only Python Revolt library readily available at the time this was
# built) hard-pins dependencies incompatible with this project's other requirements:
# aiohttp==3.7.4.post0 exactly (discord.py needs aiohttp<4,>=3.7.4, which that satisfies,
# so not the blocker) AND typing-extensions==4.0.1 exactly, which openai==1.51.0's own
# requirement (typing-extensions>=4.11,<5) flatly conflicts with — confirmed via pip's
# "ResolutionImpossible" on two separate attempts (aiohttp first, then typing-extensions).
# revolt.py appears unmaintained against current dependency versions, not just strict.
#
# The adapter code for Revolt still exists (hermes_agent/adapters/revolt_adapter.py) and
# hermes_agent/main.py still checks REVOLT_TOKEN and raises a clear error if it's set
# without the package installed — this is scaffolding for later, not dead weight to clean
# up. Re-enabling Revolt means either finding a currently-maintained Revolt library, or
# installing revolt.py with `--no-deps` and manually supplying compatible versions of its
# actual sub-dependencies (untested here — see the module docstring in revolt_adapter.py).
# Discord-only is fully unaffected either way.
