cv-hermes

A cybersecurity learning lab built on the official Hermes Agent.

This project runs the official Hermes Agent image with its recommended settings, in a controlled VM and Docker environment. The focus is the OWASP Top 10 for LLM Applications (2025), the security risks specific to AI-powered systems.

What it is

  • The official agent image, pinned, with its dashboard and API behind a login or key.
  • Discord as the chat interface. The bot's only internet hosts are discord.com and gateway.discord.gg, through an egress proxy.
  • A local model served by LM Studio. No cloud LLM provider.
  • Grafana and Loki for observing the agent's logs.

What it is not

  • Not air-gapped. The agent has two outbound hosts, and this is documented as an accepted risk.
  • Not yet a rogue-entity detector. That's designed (a separate read-only sensor) but not built.
