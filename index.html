Design rules

Credentials required

The dashboard and the API both need a login or key. Nothing is open to the internet.

Egress restricted

One proxy, two allowed hostnames, and every other outbound connection rejected at the host firewall.

Local models only

The language model runs on a local machine. No cloud model provider is used.

Observable

Logs ship to Grafana, with no route out, so the dashboards stay inside the lab.

Setup, at a glance

  1. Create a VirtualBox VM and a private host-only network.
  2. Run the provisioning script, which installs Docker and the firewall rules.
  3. Load a local model in LM Studio on the host, with a 64K context.
  4. Fill in the local environment files, then start the stack with Docker Compose.
  5. Verify the egress checks and the chat reply.
